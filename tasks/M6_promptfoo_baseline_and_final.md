# M6 — Reconstructed baseline, final promptfoo suites and stateful oracles

**Goal:** Provide real evaluation evidence and runnable `npx promptfoo eval`.

## Work

- Keep inherited seed and prompt intact. Build a clearly labeled reconstructed baseline wrapper using original prompt/tools/mock with minimal documented glue (may be poor; preserve its bugs).
- Run inherited seed and capture actual results, config/model, limitations, invalid test expectations, errors. No retroactively invented historical score.
- Build final `provider.py` implementing promptfoo `call_api(prompt, options, context)` via **shared SophieRuntime**.
- Final root `promptfooconfig.yaml` supports single-turn tests, plus isolated full multi-turn scenarios S01–S18 through scenario runner.
- Scenario runner sends real utterances through runtime, uses deterministic caller profile to handle expected follow-ups, captures transcript + final snapshot + event log. Prevent shared global state across tests.
- Deterministic Python assertions inspect booking records, transfer/lead effects, tool trace, grounded facts and forbidden claims. LLM rubrics only for voice quality, not DB truth.
- Label critical tests; one critical failure blocks release regardless of weighted overall pass. Document how the broken `question` field and contradictory seed claims are corrected in final suite.

## Acceptance

- `npx promptfoo eval` at repo root runs final suite with documented env (may require valid model/grader key).
- Backend tests still pass offline. Baseline and final artifacts generated by actual commands, include failures; no misleading comparison if models differ.
- Every original seed case mapped to corrected/retained/removed with a reason. All nine tools and all assignment scenarios have appropriate verification.
- Critical assertions inspect persisted data, not only friendly wording.
