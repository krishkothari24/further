# M3 LLM and CLI contract

`SophieRuntime` is the shared `PolicyRuntime` with a Responses proposal source. The model sees a versioned prompt (`sophie-m3-v1`) and nine strict function schemas. Its tool calls are suggestions. Read tools may return canonical facts or availability to the model. Suggested writes return `policy_gate_required`; only the persisted policy workflow can execute a write after caller intent, contact/slot readback, and service validation. Model draft speech is never used to announce an action or a fact.

The OpenAI Python SDK adapter uses `responses.create`, `parallel_tool_calls=False`, `store=False`, a flat strict schema, and original `call_id` values for `function_call_output`. All fields are required in each schema; nullable strings express optional values. The loop allows at most four tool calls and a final no-tools response. A contradictory multi-call model response is rejected. The SDK request is tested with a fake client; the real API is not verified until the owner supplies a key and opts in to the smoke command.

The deterministic speech layer reads the canonical registry for fact answers, including compound questions. Unknown Kosher meals, couple arrangements, waiver, exact room price, temperature control, and clinical suitability produce uncertainty and a staff follow-up offer. Dogs have a 30-pound limit; an unspecified golden retriever is not approved. Read-after-write evidence determines success wording. A failure after a verified write falls back to deterministic outcome wording. Structured events have no raw caller text, contact, model draft, or secret.

The CLI requires an explicit SQLite path, sandbox choice, conversation choice, and fixture clock when creating a sandbox. `/state` prints tour IDs, local dates/times, timezone, and status; `/events` prints redacted structured events. The `--offline` switch runs the same runtime with an empty proposal source. It is a diagnostic mode and does not represent live-model quality.

Known limits: M3 still uses a conservative text parser for write intent and time; unusual utterances can require clarification. Spelled emails are normalized only in the simple `j a n e at example dot com` form and always read back. The CLI stores local conversation/contact data in SQLite. HTTP authentication, scenario fixtures, UI, and promptfoo are later milestones. No live OpenAI claim is made at M3 without a key run.
